<Note>

  [dom vs native comparison](/reference/renderers) lists what differs per renderer.
</Note>

`Calendar` renders one view at a time, picked by `mode`:

```tsx
<Calendar mode="week" date={date} events={events} onChangeDate={setDate} />
```

| View                           | `mode`                           | What it is                                           |
| ------------------------------ | -------------------------------- | ---------------------------------------------------- |
| Multi-week                     | `multiweek`                      | A chosen number of full weeks as stacked event rows. |
| [Month](/guides/month-view)    | `month`                          | The classic month grid with event chips.             |
| [Time grid](/guides/time-grid) | `week`, `day`, `3days`, `custom` | Hour-by-hour columns with positioned event boxes.    |
| [Schedule](/guides/schedule)   | `schedule`                       | A vertical, day-grouped agenda list.                 |

Three more surfaces ship as standalone components rather than modes:

| Component                                     | What it is                                             |
| --------------------------------------------- | ------------------------------------------------------ |
| [MonthList](/guides/month-list)               | An infinite vertically-scrolling list of months.       |
| [ResourceTimeline](/guides/resource-timeline) | Rooms/people/machines as lanes over one day's hours.   |
| [DateRangePicker](/guides/date-picker)        | Date and range picking, standalone or as a form field. |

## Custom day counts

`custom` renders any number of columns. Set `numberOfDays` (e.g. `5` for a
work-week), or set `weekEndsOn` to show a fixed slice of the week
(`weekStartsOn`…`weekEndsOn`) that pages week by week.

```tsx
<Calendar mode="custom" numberOfDays={5} date={date} events={events} onChangeDate={setDate} />
```

## Multi-week grids

Use `mode="multiweek"` to show full weeks as stacked rows without hourly slots.
`numberOfWeeks` defaults to `2`. The first row is the week containing `date`,
aligned backward to `weekStartsOn` (Sunday by default).

```tsx
import { useState } from "react";
import { Calendar } from "@super-calendar/native";

export function MultiWeekCalendar() {
  const [date, setDate] = useState(new Date(2026, 11, 28));
  return (
    <Calendar
      mode="multiweek"
      numberOfWeeks={3}
      weekStartsOn={1}
      date={date}
      events={[]}
      onChangeDate={setDate}
      onPressEvent={(event) => console.log(event.title)}
    />
  );
}
```

React DOM and Solid use the same mode and prop names. `custom` continues to show
hourly columns, including when `numberOfDays` exceeds seven.

- Previous and next move by `numberOfWeeks` calendar weeks, including across DST,
  month, and year boundaries. Hidden weekdays shorten each row without changing
  the page step. Hiding all seven weekdays restores all days.
- Every displayed date belongs to the requested period. `showAdjacentMonths` and
  native `showSixWeeks` do not affect this mode. Titles include both date endpoints.
- Event bars, overflow, selection, all-day creation, and event moves work as in the
  month view. Existing month styling slots and render overrides apply. Custom event
  renderers and accessibility callbacks receive `mode: "multiweek"`.
- Web day cells support `keyboardDayNavigation`. Arrows skip hidden or disabled
  days, and Home/End stay within the displayed range. PageUp/PageDown change the
  window when `onChangeDate` is provided. Native supports swipe paging, and
  react-native-web uses left/right keys.
- Rows keep space for their content and scroll vertically when the view is too
  short. Set `height` on web `Calendar`, or a constrained `style` on web
  `MultiWeekView`. Native views fill their parent. Larger counts need more space;
  the rows inside a page are materialized, not an infinite virtualized list.

`numberOfWeeks` must be a positive safe integer. Invalid counts, invalid dates,
and spans outside JavaScript's representable date range throw `RangeError`.

For a single window without a pager, use the exported `MultiWeekView` from any
renderer. It accepts the corresponding `MonthView` event, selection, interaction,
and styling props, plus `numberOfWeeks`, but no month-membership options. Supply
already-expanded events to standalone views; `Calendar` handles recurrence and
display time zones.

In the multi-week web grid, a quick touch swipe scrolls. Hold a day or event for
400 ms, then drag to create or move. Mouse input starts immediately. Cancelling
the pointer or changing the displayed window cancels the hold or drag.

## Paging

Every paged view moves one page per swipe by default. Set `freeSwipe` to let a
fling carry across several pages (still snapping to a boundary), or
`swipeEnabled={false}` to page only programmatically. `onChangeDate` fires with
the new anchor date; `onChangeDateRange` (React Native) fires with the
`[start, end]` of the visible window. On react-native-web the pager follows the left/right arrow
keys; the dom renderer pages with PageUp/PageDown when `onChangeDate` is wired.
